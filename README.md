Documentação do Sistema Escolar

1-Descrição

O Sistema Escolar é um sistema simples desenvolvido para facilitar o acesso do estudante às principais informações de sua vida escolar.
O sistema possui páginas de cadastro, login, início, notas, presença e atividades.

2-Funcionalidades

A-Cadastro

Permite que o estudante crie uma conta informando:

E-mail
Senha
Confirmação da senha

O sistema verifica se os campos foram preenchidos, se o e-mail é válido, se a senha possui pelo menos 6 caracteres e se o e-mail já está cadastrado.

B-Login

Permite que o estudante entre no sistema utilizando seu e-mail e senha cadastrados.

Após o login, o usuário é direcionado para a página inicial.

C-Página inicial

Funciona como um menu de navegação, dando acesso às principais áreas:

Minhas Notas
Minha Presença
Minhas Atividades

Também possui a opção de sair da conta.

D-Notas

O estudante pode visualizar e editar suas notas. O sistema calcula automaticamente a média das matérias.

E-Presença

Permite registrar a presença do estudante durante os dias letivos de 2026. A página também apresenta um resumo com:

Dias registrados
Presenças
Faltas
Frequência

F-Atividades

Apresenta as atividades escolares do estudante, organizadas por matéria.

É possível:

Visualizar a atividade
Ver a data de entrega
Marcar uma atividade como concluída
Desmarcar uma atividade
Filtrar as atividades por matéria

3-Tecnologias

O sistema foi desenvolvido utilizando tecnologias básicas de desenvolvimento web:

HTML — estrutura das páginas;
CSS — aparência e organização visual;
JavaScript — funcionalidades e validações;
LocalStorage — armazenamento dos dados no navegador.
